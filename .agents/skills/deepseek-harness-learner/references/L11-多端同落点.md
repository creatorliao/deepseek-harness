# L11 · 多端同落点（技能可到处装，课文只回本仓）

本机可以把技能部署到很多目录，Cursor / Pi / Claude Code / 其它智能体都能读到。**技能副本可以多份；学堂正文只能有一份。** 无论在哪个客户端提问，调查路径、写入格式、操作流程、验收规格都走本文件 + [L02](./L02-落点与文种.md)。这样 Obsidian 只打开本仓学堂夹就能看到全部课。

## 1. 两套路径，不要混

| 套 | 放什么 | 可以多份吗 |
|----|--------|------------|
| **技能部署** | `SKILL.md`、本包 `references/` | 可以。家目录、各客户端各有一份，方便随处触发 |
| **学堂金库** | `需求_` `方案_` `教程_` `问答_` `00-README`、课图、讲义 | **不可以。** 只在本工作区那一个夹 |

智能体从家目录技能被唤醒，**不改变**金库位置。部署目录不是笔记本。

## 2. 本机技能常出现在哪（只读，不往这里写课）

工作区真源（本仓自有技能）：

```text
{工作区根}/.agents/skills/deepseek-harness-learner/
```

本机常见全局部署（skill-publish「全部位置」一类；各客户端还会再扫自己的目录）：

| 路径 | 谁常读 | 写教程时 |
|------|--------|----------|
| `~/.agents/skills/<name>/` | Cursor、Pi、其它读 agents 的客户端 | 可触发技能；**禁止**当学堂 |
| `~/.claude/skills/<name>/` | Claude Code 等 | 同上 |
| 本机 `builtins` 技能树（若有） | 部分启动器 | 同上 |
| `~/.cursor/skills/<name>/` | 仅当显式发到 Cursor 全局 | 同上；且不要当本技能第二真源 |
| `{工作区}/.cursor/skills/` | 个别 Cursor 配置 | **禁止**复制本包到这里当分叉 |

以上路径会漂、会过期。正文与调查**不**以它们为准。

## 3. 先认工作区，再动笔

必须同时满足，才允许落盘：

1. 当前会话的工作区根是 **deepseek-harness 叠加仓**（本机常见：`D:\code\deepseek-harness`，以实际打开的根为准）。
2. 根下存在学堂夹：`dev-docs/01-Projects/R20260820-02-学习教程/`。
3. 写入只用该夹的相对路径；文件名、文种见 L02。

认根办法（够一条即可）：根上有 `AGENTS.md` 且含「创作者叠加」学堂短句；或能列出上述学堂夹。

**工作区不是本仓**（打开了别的项目、只有家目录、只有对话）：

- 可以口头讲步骤。
- **禁止**把 `教程_` 写到桌面、下载夹、客户端 Memories、另一 Obsidian 库、官方 `docs/`、技能部署目录。
- 回复里写清：请打开本仓再问一次；打开后结果仍进同一学堂夹。

本仓与全局技能正文冲突时：**以工作区 `.agents/skills/deepseek-harness-learner/` 为准**，并在对话里说一声「按工作区技能」。

## 4. 调查、流程、格式、验收（四锁）

和在 Cursor 里问、在 Pi 里问，同一套。

| 锁 | 固定指向 | 不指向 |
|----|----------|--------|
| **调查** | ① 本仓源码与界面词典 ② 学堂夹已有课/问答 ③ 不够再公开文档 / GitHub（[L04](./L04-证据收集.md)） | 上次在别的客户端的聊天稿；家目录过期技能里的旧 L02；另一份笔记库 |
| **流程** | SKILL 工作流 1→6；九场块顺序（[L01](./L01-核心场景.md)） | 各客户端自己的「帮你记在侧栏」 |
| **格式** | YAML、`[!abstract]`、`[!question]`、双链、附录（[L07](./L07-课文版式与双链.md)）；图 [L08](./L08-可视化.md)；标签 [L09](./L09-标签与重点.md) | 客户端专属笔记语法当正文真源 |
| **验收** | 下面 §5 与各场验收同一张 | 按客户端另出一套勾选 |

外援出图/PPT 的产物文件名仍进学堂夹，见 [L10](./L10-能力路由.md)。大体积视频先问路径。

## 5. 验收（S-home-one 与写课共用）

- [ ] 新文件或修订只出现在 `dev-docs/01-Projects/R20260820-02-学习教程/`。
- [ ] 未写入家目录技能树、`.cursor/skills`、桌面、下载夹、官方 `docs/`、第二学堂夹、旧夹名「初学者学习教程」。
- [ ] `需求_` 追加了原话；`问答_` 有对应 Q；课程表/`00-README` 已更新（写课当场）。
- [ ] 课文格式仍是 L07；调查仍是 L04。
- [ ] 对话里的步骤与夹内文件一致（换一个智能体打开同一文件，读到的是同一份）。
- [ ] 用户把本仓学堂夹（或本仓根）当 Obsidian 库时，能双链打开，不必去各客户端笔记里找。

## 6. 不要

- 因为「这个智能体读的是 `~/.claude/skills`」就把课写到技能旁边。
- 为 Pi、Cursor 各写一份教程。
- 只在聊天里写完一篇当交付（笔记本打不开对话记录当库）。
- 把工作区技能再复制一份到全局，然后改全局那份当真源（改技能仍只改工作区，见 [L06](./L06-维护落点.md)）。
