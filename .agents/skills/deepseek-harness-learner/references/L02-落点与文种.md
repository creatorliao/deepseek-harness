# L02 · 落点与文种（技能内）

本文件是学堂落盘规则的**内化摘取**。冷启动只读本技能即可执行。

## 1. 唯一学堂夹

在当前工作区（DeepSeek Harness 叠加仓）里，学习类材料只进**一个**主题夹：

```text
{工作区根}/dev-docs/01-Projects/R20260820-02-学习教程/
```

- 夹号 `R20260820-02` 不改。
- 曾用名 `R20260820-02-初学者学习教程` **已作废**。目录树里若只剩旧名，先改回现名再写文件，不要平行再建夹。
- 不写官方 `docs/`。不另开「进阶教程」「培训手册」第二夹。入门 / 进阶 / 专题都进这一夹。

索引文件固定名：`00-README.md`（课程表、文档索引、决策索引）。

## 2. 夹内扁平

一层文件，不建 `教程/` `问答/` 子目录。文件名：

```text
{YYYYMMDD}-{NN}-{文种}_{短标题}.md
```

当日同一夹序号两位递增。`00-README.md` 是唯一不用日期前缀的文件。

| 文种 | 何时用 | 修订规则 |
|------|--------|----------|
| `需求_` | 该主题全部需求一份 | 只修订，不新开需求2 |
| `方案_` | 该主题方案一份 | 决策写在方案「决策记录」 |
| `教程_` | 一课一篇 | 新课新文件；课号在标题里 |
| `问答_` | 原话 + 调查题 + 答案摘要 | 追问追加一节，不另开夹 |

## 3. 一次写教程要动哪些文件

1. `需求_`：追加「提问原话」（未整理原句；追问只追加，不删旧句）。
2. `问答_`：追加 Q 节：原话、调查题、答案摘要、链到课文。
3. 新课或修订已有 `教程_`（追问同一主题则改旧课，调查题与附录一起更新）。
4. `00-README.md`：课程表 + 文档索引。主线 / 后学 / 等级写在表里。

当前默认主线是**网页入口**；命令行列后学，除非用户点名要写命令行。

## 4. 教程正文结构（阅读顺序）

版式细节见 [L07](./L07-课文版式与双链.md)。顺序锁死：

1. YAML（`tags` 3～5 个，见 [L09](./L09-标签与重点.md)）+ **`[!abstract]` 一句话**。
2. **`[!question]`** 只放调查题（[L03](./L03-提问增强与callout.md)）。原话不放这里。
3. 导航：上一课 / 下一课 / `[[00-README]]`。
4. 图景（可跟第一幅图，[L08](./L08-可视化.md)；像素图/讲义见 [L10](./L10-能力路由.md)）→ 步骤 → 边界 → 验收。
5. **相关与参考**（双链）。
6. **附录 · 原始输入**（[L03](./L03-提问增强与callout.md) §4）。

一段只讲一件事。步骤可照抄。专有名词第一次出现给一句人话。读者要能从本课跳到相近主题，不能只停在当前问题上。

## 5. 可选 overlay

若工作区根有 `AGENTS.md` 且含「创作者叠加 / 学习教程」短句，与本文冲突时以**本文 + 现场夹名**为准；不要把宿主 AGENTS 当作技能运行时必读。

技能可以装在 `~/.agents/skills`、`~/.claude/skills` 等处（[L11](./L11-多端同落点.md)）。**文种、文件名、要改的四份索引（需求 / 问答 / 教程 / 课程表）不因客户端而变。** 工作区不是本仓则不写盘。
