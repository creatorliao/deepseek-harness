# L07 · 课文版式与双链（Obsidian）

学堂课文同时给 Git 网页和 Obsidian 库读。版式固定。

读者要能**平行展开**相近主题。底部必须留关联。原话可追溯，见文末附录。

## 1. 顶部：YAML + 一句话

YAML 先写（Obsidian Properties）。`tags` 3～5 个，规则见 [L09](./L09-标签与重点.md)。

```yaml
---
title: 课 NN · 短标题
description: 与 abstract 同一句
tags:
  - dsh/教程
  - dsh/概念
  - dsh/主题词
aliases:
  - 人会搜的短名
---
```

标题之后、问题 callout 之前：

```markdown
> [!abstract] 一句话
> {学完能带走的那一句，不要第二句。}
```

`description:` 与 abstract 同义，便于 Dataview。

## 2. 文首问题框

只放调查题，见 [L03](./L03-提问增强与callout.md)。然后才是上一课 / 下一课导航（`[[文件名|显示名]]` + 相对链接）。

## 3. 正文中的图与重点

图景后可接第一幅图；步骤里最难点可再一幅。默认 Mermaid，细则 [L08](./L08-可视化.md)。像素插图与讲义 PPT 的文件名 [L10](./L10-能力路由.md)。加粗与 callout 见 [L09](./L09-标签与重点.md)。

## 4. 底部：相关与参考（必有）

验收之后、附录之前：

```markdown
## 相关与参考

### 内部（本学堂 · 双链）
- 相近主题：[[20260820-06-教程_04-网页用户旅程与API-Key|课 04 填 Key]]
- 平行展开：[[20260820-04-教程_02-命令行怎么装怎么用|课 02 命令行（后学）]]
- 课程表：[[00-README]]

### 外部（有才写）
- [官方 Web UI 指南](https://…)
```

规则：

- 内部优先 `[[文件名]]` 或 `[[文件名|别名]]`，不含 `.md`。
- 关键跳转另留相对链接，方便 GitHub。
- 平行展开至少 1 条「相近但不是下一课」。
- 外部没有就不编。中间正文不堆外链。

## 5. 附录 · 原始输入（必有）

「相关与参考」之后，见 [L03](./L03-提问增强与callout.md) §4。旧课未迁附录时，用户追问该课的当次一并补上。

## 6. 和九场的关系

| 本场 | 内部至少想到 |
|------|----------------|
| S-learn-use | 填 Key 课、安装课、命令行后学 |
| S-learn-ask | 问答篇、被问概念所属的那一课 |
| S-eng-change | 叠加原则类笔记（若夹内有方案） |
| S-train-write | 课程表、问答、同类旧课 |

## 7. 不要

- 只有当前问题、没有平行主题。
- 文首同时堆原话和调查题。
- 删附录或改写原话。
- 为 Obsidian 把学堂拆进多层文件夹。
- 用技能外绝对路径当双链目标。
