# L09 · 标签分类与重点强调（技能内）

给 Obsidian 用的收敛标签，以及正文里怎么标重点。标签像文献关键词：少、稳、能筛。

## 1. 每课 3～5 个标签

写在 YAML `tags:`（Obsidian Properties）。不要在正文再堆一排 `#`。

组成：

- **类型** 1～2 个：从 §2 闭集选。表示这篇主要在教什么认知动作。
- **主题** 1～3 个：本课**新出现**的名词或流程，小写短词，前缀 `dsh/`。
- 固定可加 `dsh/教程`（文种）。不要把九场代号做成第五个类型标签；场写在正文或 `aliases`。

合计 **3～5**。超过就砍主题，留类型。

## 2. 类型闭集（先收敛这五种）

| 标签 | 这篇主要在干什么 |
|------|------------------|
| `dsh/概念` | 定义、术语、是不是、叫什么 |
| `dsh/操作` | 可照抄的步骤、点哪里 |
| `dsh/流程` | 顺序、状态、谁先谁后 |
| `dsh/关系` | 分层、对照、A 不是 B |
| `dsh/落点` | 文件在哪、目录格式、看哪份源 |

一篇课常是「概念 + 落点」或「操作 + 流程」。不要自造第六种类型（例如再开 `dsh/理论`）。边界、红线用正文强调和 `[!warning]`，不必单独占一个类型标签。

主题标签示例（按课新增，不要预建长名单）：`dsh/预设`、`dsh/密钥`、`dsh/插件`、`dsh/session-log`。同一主题多课共用同一个词，便于反链筛选。

## 3. 重点怎么标

教练先标出本课要点，再在正文里让读者一眼看见：

- **加粗**只加在改变理解的那几个词或短句（术语首现、分层结论、锁死规则）。
- 术语第一次出现：**加粗** + 半句人话。后文不再加粗同一词。
- 步骤里的按钮文案用「」或 **加粗** 之一，一篇课内统一。
- `[!warning]` / `[!tip]` 每课各至多一个；给红线或易踩坑，不给鼓励语。

不要：整段加粗、满页标题加粗、用 CAPS 或「务必」代替加粗。

## 4. 双链仍按 L07

标签负责**分类筛选**；双链负责**跳到那一篇**。新概念若已有课，正文用 `[[文件名|显示名]]`，不要只丢一个标签当解释。
