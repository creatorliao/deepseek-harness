# L03 · 提问增强、调查题与附录原话

你是资深教练。用户原话是**证据**，整理后的问题才是**调查输入**。两份都要留下。

## 1. 为什么要增强

原话常省略对象、验收、约束，也常有错别字和口语词（如 apik）。若直接拿原话去搜仓库，会漏条件和验收。

增强时：

- 保住核心意图，不替用户改目标。
- **稍作**完善：对象（网页 / 命令行 / 改装 / 教别人）、起点、学完能做什么、约束。
- 纠正错别字；把口语换成本仓术语（API Key、Agent 预设、宿主插件），括注用户原用词一次即可。
- 对照夹内已有 `问答_`：用来选角度，不编造用户没提过的目标。
- 默认读者可能是开发者、学习者、培训师、产品经理；课里用小标题分开「你自己用」和「你讲给别人」。

禁止：把原话润色完就当原话删掉；借增强塞进用户没问的大主题。

## 2. 谁当调查输入

```text
用户原话（一字不改）
    → 教练整理成「调查题」
    → 只用调查题去做 L04 取证和写正文
    → 原话进入附录，永不删除
```

文首 `[!question]` **只放调查题**。不要把原话堆在文首和调查题抢注意力。

## 3. 文首 callout

每篇新课或实质性修订，标题和 `[!abstract]` 之后用：

```markdown
> [!question] 这一课要解决的问题
> {调查题：对象、起点、学完能做什么、约束。一段或短列表。}
```

不认 `[!question]` 时可用 `> [!NOTE]`，仍只放调查题。

## 4. 附录 · 原始输入（必须）

课文在「相关与参考」**之后**固定一节，标题就叫 **附录 · 原始输入**：

```markdown
## 附录 · 原始输入

按时间从旧到新。除标点空格外不改写。

### {日期} · 首问
> {一字不改的原话}

### {日期} · 追问 1
> {一字不改的原话}
```

`需求_` 的「提问原话」和 `问答_` 的「原话」仍要各留一份，与附录同文。三处原话必须对得上。

## 5. 追问怎么并进同一课

同一主题继续问（例如还在问预设、还在问 Key）：

1. 原话追加进 `需求_`，并在课文附录加一节，**不删旧节**。
2. 用新旧原话**重新**写成一道调查题，替换文首 `[!question]`（只此一份调查题）。
3. 把新事实写进该课**恰当小节**（定义、落点、边界），不要另开平行课，除非已经换成另一个主题。
4. `问答_` 追加新 Q 节；调查题与文首同文。
5. 需要时补一幅图或改验收，仍遵守 L08 两幅上限。

换主题则新开 `教程_`，旧课附录不动。

## 6. 问答篇

`问答_` 每一节：

1. `## Qn · 短标签`
2. **原话**（引用块）
3. **调查题**（与课文文首同文）
4. **答案摘要**
5. **正文**：链到本夹 `教程_`

## 7. 示例

原话：「网页怎么填 apik」

调查题：

> 作为本仓库的网页用户，从已能打开本机 Web 入口开始：第一次弹窗和「设置 → 模型」分别把 DeepSeek API Key 填到哪里、保存后为什么看不到明文、密钥落在哪、不要写进对话或 Git；学完能独立完成填 Key、选工作区并知道哪几条会让任务失败。当前不展开命令行。
