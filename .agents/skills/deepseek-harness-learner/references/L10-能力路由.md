# L10 · 能力路由（出图 / 出片 / 出 PPT）

本技能管**写课、落盘、调查题**。像素插图、培训 PPT、从录像抽页、给视频贴封面、把本仓网页跑起来，**不在本目录重写实现**。判定需要后：**Read 对应技能的 `SKILL.md`，按该技能工作流执行**，再把产物路径写回课文。

冷启动不必读技能外文件。一旦判定要外援，**必须**去读那份 `SKILL.md`，禁止凭记忆手写 ffmpeg、百炼 HTTP 或第二套生图参数。

## 4. 执行铁律

1. **本技能不停**：外援期间仍负责原话、调查题、课文块顺序、问答、课程表。外援只交文件路径。
2. **渐进加载**：只 Read 对方 `SKILL.md`；对方要求再 Read 其 `references/` 时按对方索引来，不要一次倾倒。
3. **确认**：`mp4-tools` 写操作（embed / apply / parts `--yes`）必须先计划后确认。百炼直出插图：用户已点名「出图」可按对方 WF 默认可直出；用户说「先别调用」则停在选型。
4. **界面证据 ≠ 生图**：按钮文案、设置页布局以本机界面或录像抽帧为准（先 `dsh-web-run` 或 `mp4-tools` 抽页）。禁止用 AI 图冒充「当前网页长这样」。
5. **密钥**：不把 API Key 写入课文、文件名或图里的文字。
6. **禁止手写**：禁止手写 ffmpeg；禁止在本技能里写 DashScope HTTP；禁止用对话内随意画图工具顶替已选定的 `bailian-ai-master` 流程。
