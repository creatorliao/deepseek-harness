# L08 · 可视化（技能内）

每篇教程放 **1～2 幅**图，帮助读者抓住本课要点。图是教练设计，不是装饰。

## 1. 先认要点，再决定画什么

成文前在心里列出本课 **3～7 个要点**（定义、顺序、分层、落点）。只把其中最难记的 **1～2 个**画出来。

优先画：

| 要点类型 | 图种 | 适用 |
|----------|------|------|
| 谁先谁后、分支 | 流程图 | 填 Key、开会话、复制预设 |
| A 与 B 分层、包含 | 示意图 | 预设 ⊂ 智能体配置；宿主 / Agent 平面 |
| 点哪里、一屏结构 | 线框图 | 设置左侧四分、一张预设卡 |
| 状态怎么变 | 状态图 | 空白可切 / 说过话锁死 |

不要画：已经用一张表说清的对照；重复正文步骤的「第 1 步第 2 步」除非顺序本身就是难点。

## 2. 放哪

- **第一幅**紧跟「图景」：给整课一张总图（关系或主流程）。
- **第二幅**（可选）放在最难的那一步旁边：落点、锁死、对照。
- 不要在文首 callout 里塞图。不要超过两幅，除非用户点名「再画一张」。

## 3. 用什么语法（默认）

优先 **Mermaid**（Obsidian 能渲染；GitHub 也能看）。节点文字短，一句一个节点。围栏语言写 `mermaid`，第一行写 `flowchart TD` 或 `flowchart LR`。

线框图用简单 ASCII 或无样式列表即可，不要为了「像产品图」去画像素稿。

图下用 **一句**说明「这张图要记住什么」，不要再写一段解说把图复述一遍。

未点名「图文并茂 / 插图 / 封面 / PPT / 从录像抽页」时，**到此为止**，不要自动去生像素图。

## 4. 像素图、PPT、录像：走开技能，不要自己画

用户要海报式插图、培训 PPT、从录像抽页或给视频贴封面时，Read [L10](./L10-能力路由.md)，再 Read 对应技能的 `SKILL.md`。本文件不写生图参数、不写 ffmpeg。

界面长什么样用本机或抽帧，不用 AI 图冒充（L10 §4）。

## 5. 不要

- 为每个小节配图。
- 把官方架构图整页搬进学堂（超范围；链到官方页即可）。
- 图里写密钥、绝对本机用户名、未脱敏路径。
- 用必须外链才能看的图床当唯一图。
- 该外援时只用 Mermaid 顶替「图文并茂」或「给我一份 PPT」。
- 在本技能里复制一份百炼 / mp4-tools 手册。
