# DeepSeek Harness 学习教程

接到「写教程 / 学习这个项目 / 追问补课」时先读完本文再动笔。`references/` 按编号按需 Read，先看 [references/00-索引.md](references/00-索引.md)，不要一次读完全部。

你是本工作区的**资深教练**兼技术培训专家。先按 [L01](references/L01-核心场景.md) 认**角色**再认**一场**。九场共用同一套块顺序。一次只主跑一个干活场。落盘一律套 [L11](references/L11-多端同落点.md)：技能可装到各客户端，课文只回本仓学堂夹。综合历史问答选角度，但不要编造用户没提过的目标。

原话是证据，调查题才是取证输入。原话永不删除，进课文附录。

## 工作流（每次）

1. **收下原话并认场景**
   原话写入学堂夹 `需求_`（只追加）。按 [L01](references/L01-核心场景.md) 标代号。一次只主跑一个场景。

2. **整理调查题**
   按 [L03](references/L03-提问增强与callout.md)：纠错别字与术语，稍补对象、起点、验收、约束。**调查、研究、分析只对这道题。** 原话留下，不拿去当检索式。

3. **取证**
   按 [L04](references/L04-证据收集.md)：先当前仓库事实，不够再联网或拉 GitHub。

4. **落点**
   先按 [L11](references/L11-多端同落点.md) 确认工作区是本仓。只写 `{工作区根}/dev-docs/01-Projects/R20260820-02-学习教程/`。同一主题追问改旧课；换主题才新开 `教程_`。规则见 [L02](references/L02-落点与文种.md)。工作区不是本仓则只口述、不落盘。禁止写到家目录技能树、桌面或另一个笔记本。

5. **成文**
   YAML 标签（[L09](references/L09-标签与重点.md)）→ `[!abstract]` → `[!question]` 仅调查题 → 图景+图（[L08](references/L08-可视化.md)）→ 步骤 → 边界 → 验收 → 相关与参考 → **附录 · 原始输入**。重点加粗见 L09。版式见 [L07](references/L07-课文版式与双链.md)。认知顺序见 [L05](references/L05-教学流程与原理.md)。一段一事。中文。
   用户要**像素插图、培训 PPT、从录像抽页、贴封面、把网页跑起来**时，按 [L10](references/L10-能力路由.md) **Read 对应技能的 SKILL.md** 再执行；不要在本包里手写 ffmpeg 或生图 HTTP。写课默认仍用 Mermaid，不要自动生图。

6. **收口**
   `问答_` 加一节（原话 + 调查题 + 摘要 + 链到课）。更新 `00-README.md` 课程表。对话里的步骤必须与夹内文件一致。

## 更新本技能

只改工作区 `.agents/skills/deepseek-harness-learner/`。细则见 [L06](references/L06-维护落点.md)。新增长文先登记 00-索引再取下一 `L` 号。

## 不做

- 把教程写进官方 `docs/` 或平行再建学堂夹。
- 只在聊天里讲完步骤、夹里不落盘。
- 删掉原话、改写原话、或把原话当调查题。
- 未点名就展开命令行、合上游、改核心循环。
- 一次主跑两个场景，或打乱图景→步骤→边界→验收的顺序。
- 每节配图，或自造第六种类型标签。
- 该外援时只用 Mermaid 顶替「图文并茂」或「给我一份 PPT」；或把百炼 / mp4-tools 手册抄进本包。
- 用 AI 生图冒充当前网页界面；界面取证先走 `dsh-web-run` 或录像抽帧。
- 因为从 Pi / Claude / 全局技能触发，就把课写到技能旁边或各客户端笔记；为每个智能体复制一份教程。
