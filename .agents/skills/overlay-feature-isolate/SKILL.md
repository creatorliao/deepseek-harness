## 流程

1. **归档**：该主题夹已有提问原话、需求（一份）、方案、决策索引。缺则先补档，停。
2. **落点表**（先给人看，再改代码）：意图 / 路径 / 层 / 是否改官方文件。能 L2 则不碰官方包。
3. 等人说「按计划执行」或确认落点。
4. L2 写主体。官方侧只加具名挂钩或整行 patch。禁止先改 `agent-loop`。
5. 挂钩名写入主题夹 `00-README`。只 `git add` 本会话路径。

## 反例

把整段业务写进官方大函数；为省事改 `packages/core/agent-loop`；需求/方案写进官方 `docs/`；未归档就编码。
