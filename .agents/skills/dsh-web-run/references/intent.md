# dsh-web-run · 意图表

先认一句，再设环境变量，最后只跑 `packages/creator/dsh-web.sh`。不要另拼 `pnpm dsh web`。

| 用户大概在说 | 变量 | 脚本会做什么 |
|--------------|------|----------------|
| 运行 / 启动 / 打开网站 / 把网页跑起来 | （默认） | 已在听则只开浏览器；否则启动再开 |
| 重启 / 重新启动 / 再起一次 | `DSH_WEB_RESTART=1` | 先停占用端口的进程，再启动并开浏览器 |
| 用环境里那把 Key / 不要 unset | `DSH_WEB_KEEP_ENV_KEY=1` | 不清理 `DEEPSEEK_API_KEY` |
| 换端口、3081 | `DSH_WEB_PORT=<端口>` | 对该端口启动或打开 |

可组合，例如：重启且保留环境钥匙。

未点名端口则 `3080`。未点名重启则不要设 `DSH_WEB_RESTART`。
