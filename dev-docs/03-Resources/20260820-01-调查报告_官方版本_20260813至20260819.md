## 3. 最近一周：官方承诺了什么

下面按**官方 Release 原文**归类，再补「对学习者意味着什么」。括号内是官方列出的主要作者，便于你去对照代码所有权，不是排名。

### 3.1 rc.7（2026-08-17）— 公开首发能力快照

**新增**

- 插件可自行注册**设置卡片**（设置 UI 不再只靠内置页）。
- Codex / Claude Code **子代理任务进入 Job Panel**（后台任务可见、可管理）。
- MCP / ACP **持久化图片附件**；PTC Mode 可转发嵌套图片。

**修复**

- 极简模式持久 Bash **卡顿**。
- 大历史消息分页 **栈溢出**。
- `max-tokens` 截断后会话**无法继续**。
- Safari 输入框光标与文本错位。
- `node-pty` 升到 1.2 beta，改善 PTY 平台兼容。

**体验**

- Cordis 动态插件面板优化。
- DeepSeek 模型增加推理强度 `low`，**默认仍是 `high`**。
- 英文内置预设 `Code mode` **改名为 `PTC mode`**（产品名变更，培训材料必须改口）。
- 提问卡片可折叠并保留草稿。

**学习要点：** 首发就已经把「插件设置面、子代理任务面、多模态附件、会话韧性、PTY」当作产品主轴，而不是只有一个聊天框。

### 3.2 rc.8（2026-08-19）— 本周最重要的一次增量

**新增**

- **多模态加深：** DeepSeek 适配器可配置原生图片请求；`/goal`、`/plan` 等命令可收图文；`@` 菜单可引用**文件和会话**。
- **子代理可安装化：** Claude Code 与 Codex 作为 **Profile Bundle 按需安装**；Codex 支持非交互权限模式和**多个命名实例**。
- **Windows：** PTY 持久 PowerShell 会话，并在**极简预设默认打开**。

**修复**

- 单图过大或历史图片累计载荷过高导致**模型请求失败**。
- 取消流式生成后，已展示的回复前缀未带入后续提问和**分叉会话**（取消 ≠ 丢掉可见前缀）。
- 部分自定义 OpenAI 兼容网关因请求格式失败；**推理内容（reasoning）回传可能缺失**。

**体验**

- 路径用 `~` 表示 HOME；窄屏输入框；反馈备注改为浮层而不是挤在操作行。
- 侧栏搜索焦点、工作流面板、模型选择器批量/选中、打开本地文件失败可重试。
- `web_search` **并发多查询**；子代理 `reportDelivery` 及时反馈并**唤醒父任务**。
- 减小安装依赖体积；本地 `dsh web` **自动开浏览器**。
- 大历史会话做 **fork 更快**。

**其他（对产品经理是 P0）**

- **SQLite 后端读写/分叉更快、体积更小，数据结构不兼容。** 旧本地库不能假设平滑升级。
- 品牌： “DeepSeek Harness” 是注册商标，见仓库 `BRAND_GUIDELINES.md` / `BRAND_GUIDELINES.zh.md`。

**SDK**

- Python SDK 覆盖 **4 个内置 Agent 预设**，并带上 `rg` / glob 与 MCP stdio 所需依赖。

## 4. 按主题理解：这套技术在强调什么

把一周变更压成四条产品主线，便于记忆和备课。

### 4.1 组合，而不是改核心循环

架构原文：[everything is a plugin](../../docs/architecture.md)。运行时由 **profile + bundle + patch** 叠出来。rc.8 把 Claude Code / Codex 做成**可安装 bundle**，是这条原则的产品化：默认不绑死，需要时再叠一层。

开发者要学的词：`cordis.yml` 行、`dsh.bundle` / `dsh.profile`、`--patch`、`dsh --dump-config`。  
产品经理要盯的风险：可选项变多之后，默认路径必须仍然「开箱能聊」。  
培训师演示建议：先跑默认 `web` profile，再当场 `dsh --dump-config` 指出「刚才多出来的行来自哪个 bundle」。

### 4.2 会话日志是真相，模型看见的必须能重放

约定：**模型可见 ⟺ 已写入 session log**。本周修复都贴着这条：

- 取消流之后仍要把**已展示前缀**带进下一问和 fork（否则模型和用户看到的历史不一致）。
- 推理内容必须在每个 reasoned turn 回传（否则兼容网关/展示层丢思维链）。
- 图片有尺寸与累计载荷上限（否则「模型请求失败」表现为随机 4xx/超时，其实是上下文预算）。

开发者读：[architecture.md](../../docs/architecture.md) 的 Session / Agent / Capability 三类事件；[session 子系统](../../docs/subsystems/session.md)。  
产品经理验收：取消、分叉、截断、附件超限，四条路径都要有**用户可理解的结果**，不能只看「最后一条回复像不像」。  
培训师课堂：用一次「生成到一半点停止 → 再问一句」，对照日志里是否还留着可见前缀。

### 4.3 多模态与引用：输入从纯文本变成「工作区对象」

rc.7 解决附件能否**持久**；rc.8 解决命令和 `@` 菜单能否**当一等输入**。

建议亲手练：

1. 给 `/plan` 或 `/goal` 配一张图。  
2. 用 `@` 引用一个文件、再引用另一条会话。  
3. 连续贴几张大图，直到触发载荷限制（用来讲「失败是预算，不是模型坏了」）。

用户入口：[Web UI 指南](../../docs/user/guide/index.zh.md)、[模型与兼容网关](../../docs/user/guide/providers.zh.md)。

### 4.4 子代理是「可安装的外部运行时」，不是聊天里的角色扮演

本周把 Codex / Claude Code 从「写死在主包」推进到：

- Job Panel 可见（rc.7）  
- Bundle 按需安装、命名实例、非交互权限（rc.8）  
- 子代理阶段性报告能**叫醒父任务**（rc.8）

开发者读：`packages/subagent/` 与 [subagent 子系统](../../docs/subsystems/subagent.md)；权限模式属于交互/审批 seam，不要在 loop 里打补丁。  
产品经理：子代理失败要有**可展示事实**（本周专门有 failure-facts 合入），否则用户只看到「子任务没了」。  
培训师：先讲「父会话 inbox + 子会话独立 log」，再演示 Job Panel，最后才讲装第二个 Codex 实例。

### 4.5 Windows 与本地终端是一等公民

rc.7 修 Bash 卡顿与 node-pty；rc.8 把**持久 pwsh** 放进极简预设默认。说明官方把 Windows 开发者当主用户之一，而不是 Linux 的附属。

本仓库 CI 也以 Windows 为硬信号（见根 `AGENTS.md`）。培训若在 Win10/11 上做，优先演示 Web + 持久终端，而不是假装人人都有 bash。

### 4.6 存储与分叉：快，但可以不兼容

rc.8 明确：**SQLite 布局不兼容**。预览期政策与根 `AGENTS.md` 一致：无外部稳定消费者时，**正确底座优先于兼容垫片**；SQLite 用单调 `SCHEMA_VERSION`。

对使用者：升级 rc 后旧会话打不开或需重建，应视为**预期**，不是偶然事故。培训课前准备干净 profile / 新 `DSH_HOME`，不要用学员上周的库当教材。

## 5. 三角角色怎么用这份清单

### 5.1 开发者：本周该碰的代码面

按「先会用、再能改」：

1. 跑通 `npx @deepseek-ai/dsh web` 或源码 `pnpm dsh web`，读 [development.md](../../docs/development.md)。  
2. 读 [architecture.md](../../docs/architecture.md) + [cordis-primer](../../docs/cordis-primer.md)，会看 `dump-config`。  
3. 跟一条本周 bug 读实现（比通读 1600 个文件有效）：  
   - 推理回传：`fix(llm-deepseek): pass reasoning content back on every reasoned turn`  
   - 取消前缀：`abort-partial-finalize`  
   - 图片预算：`image-dimension-limit` / `image-request-budget`  
4. 扩展走 **plugin + bundle**，不要改 `agent-loop`，除非同步改架构文档。  
5. 实验包（Agent Teams）只当内部原型：命名前缀、禁止被正式包依赖。

日常检查用 [dsh-pre-push-checks](../../.agents/skills/dsh-pre-push-checks/SKILL.md)，不要默认全量 CI。

### 5.2 产品经理：本周的决策信号

| 信号 | 含义 |
|---|---|
| 两天一个 rc，diff 上万行 | 预览期以合入窗口发布，不是 SemVer 稳定节奏 |
| 多模态 + `@` 引用 + 命令收图 | 输入对象从「一句话」升级为「工作区上下文」 |
| 子代理可安装、可多实例 | 平台战略：宿主组合外部 agent，而不是只做一个模型聊天 |
| Job Panel / reportDelivery | 长任务必须可观察、可唤醒，否则委派不可用 |
| SQLite 不兼容、品牌规范入库 | 预览期可以断存储；对外沟通与商标同时收紧 |
| Release 不提 Agent Teams | 实验能力与用户承诺刻意错开 |

验收清单（可直接当用例）：

- [ ] 自定义 OpenAI 兼容网关能调通，且带推理的模型不丢 reasoning  
- [ ] 取消生成后再提问 / 再 fork，上下文仍含已展示前缀  
- [ ] 超大图、多图累计会失败在**预算**，而不是静默丢图  
- [ ] Windows 极简预设下 pwsh 会话可持久  
- [ ] 本地 `dsh web` 自动开浏览器；SSH 不开浏览器  
- [ ] 从 rc.7 升到 rc.8 时，对学员/客户说明**会话库可能作废**

### 5.3 培训师：建议课序（90–120 分钟可砍）

1. **定位（10 min）：** Everything is a plugin；preview 会破兼容。  
2. **上手（15 min）：** 密钥、工作区、一条总结仓库的提示（跟官方 user guide）。  
3. **看见组合（15 min）：** `dump-config`；指认 base / web-app。  
4. **本周新能力实验（30 min）：** `@` 引用、命令配图、取消再续、（可选）装 Codex bundle。  
5. **失败课（15 min）：** 图片超限、兼容网关格式、子代理失败出现在 Job Panel。  
6. **开发扩展（余量）：** [写一个 tool](../../docs/cookbook/adding-a-tool.md) 或 [插件入门](../../docs/user/develop/basic/index.zh.md)。  
7. **口播禁忌：** 不要把 PTC 仍叫 Code mode；不要把 experimental teams 讲成 GA；不要承诺会话库跨 rc 迁移。

Python 课单独开：[python-sdk](../../docs/user/guide/python-sdk.zh.md)。rc.8 起四套内置预设都在 SDK 运行时覆盖范围内。
