## Q1 · 初学者：怎么装、命令行、网页；教程放哪

**原话**

> 我是一个初学者，请你帮我分析一下当前的代码仓库，然后的话。告诉我以下的一些事情，第一，这个工具我应该怎么装，第二，作为命令行工具，我应该怎么装，怎么用？作为网页工具，我应该怎么样去启动，怎么使用？对应的教程给我。教程应该写在 `@dev-docs/01-Projects` 里面的一个专题子目录里面，将来所有的教程都写在里面，我看着这一个里面的子主题，我就可以随时的去进行学习

**答案（摘要）**

- 这是 DeepSeek Harness（`dsh`）：插件拼智能体，有网页和命令行两张脸。
- **装**：发布版用 `npx @deepseek-ai/dsh web`；本仓库用 `pnpm install`。源码开网页还要 `pnpm run build`。
- **命令行**：`pnpm dsh --help`；无界面任务 `pnpm dsh --profile headless "…"`（后学）。
- **网页**：`pnpm dsh web`，默认 `http://127.0.0.1:3080`。
- 学堂只这一夹；子主题用课程表 + 文件名，不套课程序目录。

**正文**：[课 01](./20260820-03-教程_01-仓库是什么与怎么装.md) · [课 03](./20260820-05-教程_03-网页怎么启动怎么用.md) · [课 02 后学](./20260820-04-教程_02-命令行怎么装怎么用.md)

## Q13 · 「模型」页 API 密钥被 disable

**原话**

> 这个就被disable了。

**整理后的问题**

已经进了「设置 → 模型 → DeepSeek」，「API 密钥」灰掉且写着「由启动环境提供（只读）」。这是坏了还是已有钥匙？为什么 Windows 环境变量面板是空的？若只想当用户发任务，还要不要解锁？

**答案（摘要）**

- 灰掉 = 启动 `dsh web` 的进程里已经有 `DEEPSEEK_API_KEY`，界面故意只读。钥匙可用，不是输入框坏了。
- 本机：Windows 用户/系统环境变量没有这个名字；`C:\Users\creator\.bashrc` 有。Git Bash 启动服务时带上它。仓库根和 `~\.dsh` 当时没有 `.env` / `.credentials.yaml`。
- 只想用网页：关掉设置，选工作区，直接发任务。
- 只想在网页里换钥匙：改 `.bashrc` → 关服务 → **新开**终端再启动。

**正文**：[课 05](./20260820-09-教程_05-设置页为什么录不了API-Key.md) 的「发现记录」

## Q14 · 把发现与根本原因写入课文，并重启服务再试

**原话**

> 这真是个非常有趣的发现，请你帮我把这个发现记录到刚才的文档里，把这个问题记录进去，把根本原因也记录进去，我已经清空bashrc的内容，请你帮我重新启动服务，我希望进去再试一遍。

**整理后的问题**

- 课文：[课 05 · 发现记录](./20260820-09-教程_05-设置页为什么录不了API-Key.md)。
- 清空 `.bashrc` 后仍须停掉旧进程、在 unset 后重启。只改文件、不换进程，框不会变。

**整理后的问题**

作为已经读过课 06、能打开本机网页的开发者：先用官方源码和官方文档说清「插件」怎么定义、`everything is a plugin` 怎么理解；代码格式与 `cordis.yml` 行格式分别是什么；插件一般存在哪、怎么存、怎么被取和读、怎么插进运行树、怎样改智能体最终行为；内置插件在仓内哪、官方文档哪、怎么观摩；自己开发要满足哪些导出与组装条件，本叠加仓该落哪。学完能指出核对过的文件或符号，并能把插件和 Skill、Agent 预设、设置里的「插件」页分开。本课不写官方 `docs/`，不先改装 `agent-loop`，不把命令行当产品主线。

**答案（摘要）**

- 插件 = 被 Loader 挂上的 Cordis 模块（`apply` 或 `Service` 子类）+ 配置行（`id` / `name` / `config`）。不是 Skill，不是 Agent 预设本身。
- everything is a plugin：模型、工具表、会话日志、loop 都是可替换插件；扩展方式是旁路挂载，不是打内核补丁。
- 仓内存 `packages/<组>/<包>/`；插进树靠 `packages/bundle/*/cordis.patch.yml` 叠层，再 overlay profile / home / `--patch`。
- 取读：合成条目 → Node 解析 `name` → 等 `inject` → `apply`。影响行为靠 `ctx.tools` / 提示词 / waterfall 等挂钩。
- 练手：官方 `scratch-plugin` + `--patch`。本仓要留下：`packages/creator` + 自有 patch。
