# 课 08 · 网页 Session log 怎么下、本地还在不在、样板怎么读

> [!abstract] 一句话
> Session log 是真源；对话和「轨迹」是投影；点「Session log」只是拷贝一份 ZIP，`~\.dsh\sessions` 里的源文件还在。

## 图景

你在网页上看到的「对话」，是把原始事件折成聊天气泡。下面那个 **「轨迹」** 标签，是同一段历史的另一张表：按轮次 / 工具调用摊开，仍然是**折叠后的投影**，没有导出按钮。

真正落盘的叫 **Session log（会话日志）**：一行一个 JSON，只追加、不改历史。模型下一轮看见什么，运行时是从这份 log **派生**出来的，不是另存一份「聊天记录」。

右上角按钮文案是英文 **Session log**（带下载图标）。输入框里也可以打 `/export`。两条路走同一个下载控制器：先 `HEAD` 预检，再让浏览器保存 ZIP。这条命令**不会**开一轮模型对话，也**不会**把 ZIP 写进模型历史。

---

## 步骤

### 1. 在网页上拿到一份 ZIP

1. 打开本机 Web（默认 `http://127.0.0.1:3080`），进入**已经有过对话**的那个会话。
2. 点 Header 最右侧 **Session log**，或在输入框输入 `/export` 回车。
3. 等「准备中 / 开始下载」弹窗。关掉弹窗**不会**取消已经交给浏览器的下载。
4. 浏览器另存为：`dsh-session-<会话id>.zip`。目标文件夹由浏览器决定，页面**不会**告诉你 Host 上的路径。

不要给 `/export` 加路径参数；加了会报错。保存位置只能靠浏览器的下载设置。

### 2. 解开 ZIP 看里面有什么

典型内容：

| ZIP 内路径 | 是什么 |
|------------|--------|
| `session.jsonl` | 根会话的**明文**逻辑日志（一行一条记录） |
| `subagents/<id>/session.jsonl` | 子代理自己的日志（没有子代理则没有这个目录） |
| `media/<附件id>.<ext>` | 日志里引用过的图片等（没有附件则没有） |

你这份样板解压后只有根文件 `session.jsonl`，没有子代理、没有 media。这表示当时那次会话没有派生出独立子会话树，也没有导出附件。

物理磁盘上平时往往是 `session.jsonl.zstd`（压缩帧）。导出时 Host 先读出逻辑明文，再放进 ZIP，所以你打开的是 **`.jsonl` 文本**，用任何编辑器或 `Get-Content` 都能看。

### 3. 回答「下载完本地还有没有」

**还有。** 下载是拷贝，不是剪切。

| 位置 | 下载之后 |
|------|----------|
| Host 真源 | 仍在 `$DSH_HOME/sessions`。未设置 `DSH_HOME` 时，Windows 是 `%USERPROFILE%\.dsh\sessions`，也就是 `C:\Users\<你>\.dsh\sessions` |
| 浏览器下载目录 | 多了一份 ZIP（以及你解压出来的文件夹） |

目录形状（仓内 `projectKey` / `sessionDir`）：

```text
~\.dsh\sessions\
  --<把工作区路径收成一段 slug>--\
    <编码后的 session id>\
      session.jsonl.zstd
```

没有工作区路径的会话进 `_no-cwd`。源文件会一直累积，产品**没有**「导出后删除」接口；要腾空间只能你自己在资源管理器里挪或删（先备份）。

网页关了、ZIP 删了，只要 Host 上这份还在，侧边栏里通常还能打开同一会话（损坏例外，见课 09 / 调查报告）。

### 4. 对照样板读第一行

样板目录（只作本机例子，**不要提交进 Git**）：

`C:\Users\creator\Downloads\Compressed\dsh-session-session-7db6d120-f004-40ec-8976-ab0301a7e48e\session.jsonl`

**第一行**不是事件，是 header（`type` 为 `session`）：

| 字段 | 样板里的值 | 人话 |
|------|------------|------|
| `version` | `0` | 磁盘格式版本；当前没有兼容旧格式的承诺 |
| `id` | `session-7db6d120-f004-40ec-8976-ab0301a7e48e` | 会话身份；ZIP 文件名也带这段 |
| `cwd` | `C:\Users\creator\Desktop\hermes-agent-setup` | 这次会话绑的工作区 |
| `delegationDepth` | `0` | 不是子代理会话 |
| `agentPreset` | `standard` | 当时用的 Agent 预设内部 id（课 06 的「标准」） |
| `createdAt` | 一个大整数 | 创建时刻（毫秒） |

从第二行起，每行一个事件，带单调递增的 `seq`（0, 1, 2…）。读 log 的顺序就是时间顺序。

### 5. 用白话走完样板的前几轮

不要整行复制进对话。下面只点名发生了什么。

1. **开场策略**：`permission/preset` + `sandbox/mode` + `approval/policy`。样板先是 `workspace-write`，审批 `ask`（界面上的「工作区可写 / 要问你」）。
2. **你说了一句**「目录里面有什么嘛，」。log 先把这句话放进 inbox，再 `turn/start`，再写出一条 `user/message`。
3. **插件也在说话**：紧接着还有 `user/message`，内容是运行时上下文、沙箱说明、**本机技能清单**。这些也会进模型请求，所以必须进 log。界面上你可能只看到自己那一句。
4. **点名模型**：`request/header` 记下 `deepseek-official` / `deepseek-v4-flash`。
5. **第一轮失败**：`assistant/chunk` 的 `finish` 是 `AUTH` 401，文案里 Key 被打成 `****ed90`。随后 `step/end`、`turn/end`。界面上就是聊失败；log 把原因钉死了。
6. **你改了权限**：`command/run` 名为 `permission`，参数 `danger-full-access`，接着策略改成 `never`，`command/done` 成功。这是用户命令平面，不是模型自己改的。
7. **第二轮**「你是谁？」之后才进入正常 step；样板里稍后出现 `tool/call`，工具名 `pwsh`，参数是列目录。

读法口诀：**先 header 认人，再按 `seq` 往下走；`turn` / `step` 是括号；`user/message` 是谁说了什么；`assistant/chunk` 是模型吐字或失败；`command/*` 是你打的斜杠命令；`tool/call` 是工具。**

界面底栏那些「2 rounds · LLM 6.7s · Cache hit 50%」是**当场**算的状态，不一定以同一形态再出现在 jsonl 每一行里。要复盘「当时用了哪个模型、哪句用户话、哪次工具」，看事件，不要只看底栏截图。

## 边界

- `/export` 和 Header 按钮都是**浏览器下载**，不是往 Host 某目录再写一份「导出结果」。
- 活动会话导出前会 flush：ZIP 里可能包含你刚刚按下 `/export` 产生的 `command/run` / `command/done`。冷启动已落盘的会话不需要这一步。
- SQLite 持久化后端**不能**走这条原始工件导出（会 501）。本仓网页默认是 JSONL + zstd。
- 轨迹 Tab **没有**导出。不要在轨迹里找下载。
- log 含工作区绝对路径、技能名、命令、工具参数、部分报错。密钥常见为打码，**整份仍按敏感文件处理**：不进 Git、不发给不可信方、不把全文贴回网页让模型「分析自己」。
- 学堂不收录你的样板文件；只引用短字段。

你带别人时：先让对方指出按钮和 `~\.dsh\sessions`，再让对方打开第一行读出 id，最后才打开课 09。
