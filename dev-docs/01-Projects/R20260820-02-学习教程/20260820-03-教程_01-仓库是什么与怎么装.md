## 1. 这是什么

你打开的仓库叫 **DeepSeek Harness**，日常命令是 **`dsh`**。

它不是「一个聊天网页」那么简单，而是一套**智能体框架**：用插件拼出 Agent。拼好以后，可以用两种面孔用它：

| 面孔 | 你看到什么 |
|------|------------|
| 网页（Web UI） | 浏览器里选工作区、设密钥、打字对话 |
| 命令行（CLI） | 终端里一条命令跑完一个任务，或启动网页服务 |

本工作区还叠了一层创作者文档（`dev-docs/`）。**学怎么用产品，看本夹。** 官方英文架构说明在 `docs/`，初学可以后读。

产品仍在开发者预览，升级可能不兼容旧配置。这是正常现象，不是你装错了。

---

## 2. 先选你是哪一种「装」

「怎么装」有两条路，不要混。

### 路 A：只想用发布版（不开发本仓库）

1. 安装 [Node.js](https://nodejs.org/)（建议 22 或 24）。
2. 打开终端，执行：

```sh
npx @deepseek-ai/dsh web
```

第一次会下载 `@deepseek-ai/dsh`。成功后默认打开 `http://127.0.0.1:3080`。接着学 [课 03](./20260820-05-教程_03-网页怎么启动怎么用.md)。

官方原文：[README.zh.md](../../../README.zh.md)。

### 路 B：你已经在用这个 Git 仓库（现在多半是这条）

目标是：**依赖装好，命令行能打印帮助。** 本仓把这叫做目标 A，不要求先跑完整编译。

细则与耗时：[20260820-05-最佳实践_本地环境构建效率](../../02-Areas/20260820-05-最佳实践_本地环境构建效率.md)。

## 3. 路 B 的前置检查

在仓库**根目录**打开终端（能看到根上的 `package.json`）。

```sh
node -v
pnpm --version
pnpm config get registry
```

| 检查 | 期望 |
|------|------|
| `node -v` | `v22.19` 及以上，或 `v24` / `v26` |
| `pnpm --version` | 与根 `package.json` 里 `packageManager` 一致（当前是 **11.7.0**） |
| registry | 国内常用 `https://registry.npmmirror.com/` |

没有 pnpm 时：先装好 Node，再执行 `corepack enable`，然后重新开终端。若 `corepack enable` 在 Windows 上报没有权限改 `C:\Program Files\nodejs`，只要 `pnpm --version` 已经是 11.7.0，可以不管 Corepack。

国内源优先配在**用户级** pnpm/npm，不要为了加速去改官方仓里的项目 `.npmrc`（官方一般不提交镜像）。

还没有 clone 时：

```sh
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
```

你若已经在 Cursor 里打开了本仓，跳过 clone，只 `cd` 到仓库根。

---

## 4. 路 B 的安装步骤

已有健康的 `node_modules` 时，**不要**先删再装。

```sh
pnpm install
pnpm dsh --help
```

| 结果 | 含义 |
|------|------|
| `pnpm install` 退出码 0 | 依赖装完 |
| 帮助里出现 `Usage: dsh` | 命令行入口可用 |

安装在 Windows 上可能要几分钟：包已经在本地缓存里时，慢的往往是给几百个包做链接，不是没配淘宝源。中途打断会更慢，尽量一次跑完。

日志里出现 Linux 专用 `landlock-run` 平台提示、或某个 demo 的 `.EXE` 链接警告，**只要最后退出码是 0，不要重装。**

---

## 5. 密钥：现在可以不配

能跑帮助，就算本课「装好了」。

要让模型真的回答，需要 [DeepSeek API 密钥](https://platform.deepseek.com/)。两种常见放法：

- 网页：在界面「设置 → 模型」里填（课 03）。
- 命令行真实任务：仓库根目录建 **不要提交** 的 `.env`，写 `DEEPSEEK_API_KEY=sk-...`。

没有密钥时，网页能开、帮助能看；带模型的任务会失败或跳过。这不是安装失败。

---

## 6. 先别跑的命令

| 命令 | 什么时候才需要 |
|------|----------------|
| `pnpm run typecheck` | 要对齐官方贡献者「first-time setup」，或改类型 |
| `pnpm run build` | 要完整前端产物、或官方「从源码跑 Web」那条路径 |
| `pnpm run test` / `test:coverage` | 改代码并要证据时 |

官方 README 的「从源码运行」写了 `pnpm run build` 再 `pnpm dsh web`。那是**完整网页产物**门槛。本课只验 CLI 帮助。
