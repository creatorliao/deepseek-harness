## 适用

有上游、要反复合入、自研是叠加而不是另造一棵树。本仓官方扩展点是插件 / bundle / `cordis.patch.yml`。

## 原则（短）

- 新能力先落 L2。能插行就不改官方包。禁止先改 `agent-loop`。
- 合 `upstream/master` 当前树，不挑 commit 声称已对齐。
- 先归 L1 / L2 / L3 / 枢纽，再选 ours/theirs。枢纽禁止整文件取一边。
- 产品默认本仓说了算；官方新能力字段要留。
- 先归档提问原话、需求、方案、决策，再实施。
- 本仓写入根 `AGENTS.md` 的段落用中文。

## 落点（意图 → 路径）

| 意图 | 落点 |
|------|------|
| 规格 | `dev-docs/02-Areas/` |

## 日常

从 `dev-creator` 拉 `feat/` 或 `fix/`。先给落点表，等人确认再改代码。只 `git add` 显式路径。

## 同步（T0～T5）

T0 归档 + 三颗 hash + 工作区干净。T1 `merge upstream/master`。T2 机械冲突。T3 上游正文为底缝挂钩。T4 祖先检查 + 清单回归 + 窄门。T5 更新停点；未授权不合回、不推官方。

根 `AGENTS.md` 冲突：上游全文为底，缝回中文短节。

## 效力

你当轮一句话 > 主题夹 `00-README` > Areas 规格/本文/清单 > AGENTS 短节 > overlay skill > 官方其余 AGENTS。

## 入口

使用者只记 `/pmi-pm-ai-leader`。步骤在 `overlay-feature-isolate` 与 `overlay-upstream-sync`。
